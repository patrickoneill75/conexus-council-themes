How to get an exported HTML file

      
This control panel can't pull an artifact's content from a
        claude.ai link by itself -- there's no API for that. Instead:

      
    
        
  1. In a Claude Code or claude.ai session, ask Claude to export the artifact:
          paste the artifact's claude.ai/artifact/... link and ask it to read
          the page and save the raw HTML. This only works for an artifact you own;
          one shared with you (not created by you) only yields a summary, not the full
          page -- "remix"/duplicate it into your own account first if that's the case.
    2. 
        
  2. Claude hands you the saved .html file.
    3. 
        
  3. Upload that file below, set a title, description, and whether it should be
          public or private, and submit.
    4. 
      

      
One real limitation: an artifact that reads live
        data or shared storage via Claude's runtime capabilities (window.claude.*)
        depends on claude.ai's own backend. Those calls simply fail once rehosted here --
        this catalogue is for genuinely self-contained artifacts.
