Council Meeting Helper Upload

A fresh export of the Council Meeting Helper — one row per meeting, with its Year/Quarter/Region. Each export already contains the full history plus anything new, so this replaces the file in the Data Folder wholesale.

Post-Meeting Survey Upload

A fresh export of every respondent's answers, across every meeting. Also cumulative, so this replaces the file in the Data Folder wholesale — Year/Quarter/Region for each response are resolved automatically from its Meeting Date via the Helper file above.

Update Dashboard

Reads the Data Folder's two files, figures out which meetings aren't published yet, and for each one: asks Claude to extract "areas to improve" items tagged to the existing category taxonomy, appends them to the Feedback Log, then publishes that quarter's top issues plus what's recurred quarter-over-quarter and year-over-year. Also rebuilds the quant dashboard from the same two files. No upload needed first if the files are already current in Box.

Meetings

Every meeting with data currently published, across both dashboards. Select one or more and Remove & refresh to delete their entries from the Feedback Log and both dashboards, then re-synthesize whatever's left -- a removed meeting can have been part of another quarter's QoQ/YoY pool. Also removes the matching rows from the Data Folder's own Helper and Survey exports in Box, so it doesn't come back on the next Update Dashboard -- best-effort: if Box isn't reachable or the meeting has already aged out of the current export, only the published data gets cleaned up.

Data Folder

The one Box folder holding all three source files: Council Meeting Helper.csv and Post-Meeting Survey.csv (kept up to date from the two upload cards on the main page) and a Content Categories file, .csv or .xlsx (maintained directly in Box — it changes rarely enough not to need an upload path). Set this once — you can change it later, but there's no need to touch it again quarter to quarter.

Refresh

Re-publish from what's already been extracted — no new Claude extraction, and no auto-detecting new meetings. Refresh Dashboard merges whatever's currently in the Data Folder into the quant dashboard (use after editing something directly in Box; it only ever adds or updates a meeting, never removes one). Refresh Themes re-synthesizes every quarter already in the Feedback Log (use after a taxonomy change, or to redo past quarters from scratch). Refresh All does both.
