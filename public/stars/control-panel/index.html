No Claude call here, ever -- occupations.json is generated
      by a deterministic local script (generate_data.py, reading the O*NET
      skill-model workbook and an Indiana wage export) and the per-skill development-focus
      text is a static, hand-written lookup table already checked into this app's code.

      and refreshes what the live tool serves -- it never re-runs any extraction.
