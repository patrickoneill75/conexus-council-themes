2. Scan

A scan also runs by itself every morning. It lists the folder, skips every file Box says has not changed, and calls Claude only for text it has never read, so a day with no new notes uses none. Every Claude result is saved and reused.

Start with the trial run. It reads five files so the first cost is small and you can check the results before the full scan.

3. Partner list

Industry, member status and contacts come from here, and it is how a company named in the notes is recognized. Update it whenever partners join or leave: upload a fresh Salesforce export, or edit one partner below. Nobody is deleted by an upload. A partner missing from a full list is marked Former member and keeps their history.
